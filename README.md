# Cab Fare Prediction

## Project Overview

Cab Fare Prediction is a Data Science and Machine Learning project developed to predict the fare amount of a cab ride based on various input features such as pickup location, drop location, distance, time, and passenger count.

The main goal of this project is to estimate the expected cab fare before booking, helping both customers and service providers make better decisions.

This project uses data preprocessing, exploratory data analysis (EDA), feature engineering, and regression models to improve prediction accuracy.

---

## Features

* Data cleaning and preprocessing
* Handling missing values and outliers
* Exploratory Data Analysis (EDA)
* Feature engineering using time and distance
* Regression model building
* Model evaluation using MAE and RMSE
* Fare prediction visualization

## Dataset Details

The dataset contains:

* Pickup location
* Drop location
* Pickup date and time
* Passenger count
* Fare amount
* Latitude and Longitude values

These features are used to train the machine learning model for accurate fare prediction.

---

## Machine Learning Models Used

* Linear Regression
* Random Forest Regressor
* Gradient Boosting Regressor

The best model is selected based on prediction accuracy and evaluation metrics.

---

## Working Procedure

1. Load the dataset into Pandas
2. Perform data cleaning and remove null values
3. Detect and remove outliers
4. Convert date and time into useful features
5. Calculate ride distance using latitude and longitude
6. Split data into training and testing sets
7. Train regression models
8. Evaluate model performance
9. Compare predicted fare with actual fare
10. Visualize the final results
